# 中证1000（512100）低开高走概率分析

> 数据范围：2024-01-08 ~ 2026-08-14（共 630 个交易日，前复权日线）
> 口径：低开 = 开盘价 < 昨收；高走 = 收盘价 > 开盘价（日内低开回升）；翻红 = 收盘价 > 昨收

## 一、总览

| 指标 | 数值 |
|---|---|
| 交易日数 | 630 |
| 低开天数 | 396（62.9%） |
| 低开且日内高走 | 220（**占低开日的 55.6%**） |
| 低开且收盘翻红 | 179（**占低开日的 45.2%**） |
| 低开高走占全部交易日 | 34.9% |

**结论：中证1000 低开后日内回升（高走）的概率约 55.6%，收盘站上昨收（翻红）的概率约 45.2%。**
