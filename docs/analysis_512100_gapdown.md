# 中证1000（512100）高开低走概率分析

> 数据范围：2024-01-08 ~ 2026-08-14（共 630 个交易日，前复权日线）
> 口径：高开 = 开盘价 > 昨收；低走 = 收盘价 < 开盘价（日内高开回落）；翻绿 = 收盘价 < 昨收

## 一、总览

| 指标 | 数值 |
|---|---|
| 交易日数 | 630 |
| 高开天数 | 194（30.8%） |
| 高开且日内低走 | 73（**占高开日的 37.6%**） |
| 高开且收盘翻绿 | 56（**占高开日的 28.9%**） |
| 高开低走占全部交易日 | 11.6% |

**结论：中证1000 高开后日内回落（低走）的概率约 37.6%，收盘跌破昨收（翻绿）的概率约 28.9%。**
