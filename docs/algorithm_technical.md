# Resonance 择时算法技术内幕

## 一、系统定位

基于 A 股宽基 ETF（默认 510300 华泰柏瑞沪深300ETF）的**多因子共振择时系统**。核心假设：国家队/机构资金通过 ETF 申赎渠道进出市场，其行为会在 ETF 份额变化、量价关系、市场情绪三个维度留下可观测痕迹。当多个维度同时发出同方向信号时（"共振"），形成高置信度的买卖时机。

---

| 数据 | 来源 | 频率 | 用途 |
|------|------|------|------|
| ETF 日K线（OHLCV） | 腾讯行情 API | 日 | 量价因子、价格位置 |
| 沪深300指数K线 | 腾讯行情 API | 日 | 超额收益、逆市护盘检测 |

| 融资余额 | akshare（东财/上交所） | 日 | 杠杆情绪分位 |

## 三、因子体系（5 个维度）

### 3.1 价格位置 (price_position)

```
price_position = (close - low_60d) / (high_60d - low_60d) × 100
```

- 回看窗口：60 个交易日
- 含义：当前收盘价在近 60 日价格区间中的百分位
- 阈值：≤40 → 低位（绿灯）；≥70 → 高位（红灯）

### 3.2 份额流向 (share_prob)

ETF 份额日环比变化 → 分段线性映射为 0-100 概率值：

| 份额变化(%) | 概率映射 |
|-------------|----------|
| > +10% | 95 |
| +5% ~ +10% | 80 ~ 95 |
| +3% ~ +5% | 65 ~ 80 |
| +1% ~ +3% | 45 ~ 65 |
| 0 ~ +1% | 30 ~ 45 |
| -1% ~ 0 | 15 ~ 30 |
| -5% ~ -1% | 5 ~ 15 |
| < -5% | 0 ~ 5 |

- 阈值：≥65 → 净申购（绿灯）；≤30 → 净赎回（红灯）

### 3.3 吸筹/出货方向 (trade_direction)

```python
if volume_ratio < 1.5:  → NEUTRAL（缩量时不判方向）
if price_position ≤ 40: → ACCUMULATE（低位放量 = 吸筹）
if price_position ≥ 70: → DISTRIBUTE（高位放量 = 出货）
else:                   → NEUTRAL
```

- `volume_ratio = 当日成交量 / 20日均量`
- 逻辑：放量+低位 = 有人在大举买入（吸筹）；放量+高位 = 有人在大举卖出（出货）

### 3.4 成交额热度 (turnover_percentile)

- 全市场两市成交额，60 日滚动窗口计算当日分位数
- 阈值：≤20% → 极冷（绿灯）；≥80% → 过热（红灯）

### 3.5 融资杠杆 (margin_percentile)

- 两市融资余额，60 日滚动窗口计算当日分位数
- 阈值：≤20% → 杠杆低位（绿灯）；≥80% → 杠杆过热（红灯）

## 四、综合概率 (composite_prob)

三因子加权合成：

```
composite_prob = vol_prob × 0.50 + dir_prob × 0.20 + share_prob × 0.30
```

（份额数据缺失时降级为：`vol_prob × 0.70 + dir_prob × 0.30`）

其中：
- **vol_prob**（量能概率）：量比分段映射，量比越大 → 越活跃 → 概率越高
- **dir_prob**（方向概率）：4 个子因子加权
  - f1 (40%): 逆市护盘检测（ETF涨+指数跌 → 高分）
  - f2 (30%): ETF vs 指数 5日超额收益
  - f3 (20%): 指数 5日趋势（越跌 → 越可能是底部护盘）
  - f4 (10%): 基线常数 35
  - 最终乘以"涨幅折扣"（指数大涨时打折，避免追高误判）

## 五、交易信号生成规则

### 5.1 买入条件（空仓时，三选一）

| 规则 | 条件 | 含义 |
|------|------|------|
| 规则1 | price_position ≤ 40 AND share_prob ≥ 65 AND trade_direction = ACCUMULATE | 价格低位 + 份额净申购 + 放量吸筹 |
| 规则2 | price_position ≤ 40 AND trade_direction = ACCUMULATE AND turnover_pct ≤ 10% | 价格低位 + 放量吸筹 + 市场极冷 |
| 规则3 | price_position ≤ 10 AND trade_direction = ACCUMULATE AND composite_prob > 60 | 价格极低位 + 放量吸筹 + 综合概率高 |

**共同前提**：`trade_direction == ACCUMULATE`（必须是吸筹状态才允许买入）

### 5.2 卖出条件（持仓时）

**出货确认日**：当日同时满足以下三条才计为一次"确认出货"：
```
trade_direction == DISTRIBUTE AND price_position ≥ 80 AND margin_percentile ≥ 90
```

**卖出触发**：
```
持有天数 ≥ 10（最短持有期）
AND trade_direction == DISTRIBUTE（当日是出货方向）
AND 累计确认出货次数 ≥ sell_threshold
```

### 5.3 卖出阈值 (sell_threshold) — 量价记忆机制

买入时根据当日量能设定卖出难度：

```python
volume_ratio = 买入日成交量 / 前20日均量

if 买入日成交额分位 ≤ 10%（极冷市买入）:
    sell_threshold = 1  # 容易卖出（冷市买入的仓位不贪）
else:
    sell_threshold = max(2, ceil(2 + volume_ratio × 0.55))
```

| 买入日量比 | sell_threshold | 含义 |
|-----------|---------------|------|
| 极冷市 | 1 | 1次出货确认即可卖 |
| 1.0x | 3 | 需3次确认 |
| 3.0x | 4 | 需4次确认 |
| 5.0x | 5 | 需5次确认 |
| 7.0x | 6 | 需6次确认 |

**设计意图**：放量买入（市场恐慌时放巨量抄底）意味着筹码交换充分，后续上涨空间大，需要更多出货确认才能离场；缩量买入（冷市悄悄建仓）则快进快出。

## 八、设计哲学与已知局限

### 设计哲学
1. **只吃鱼身**：不抄底不逃顶，等确认信号再动。宁可少赚，不可深套。
2. **多维共振 > 单一指标**：任何单一因子都可能失效，但 3-5 个独立维度同时异常的概率极低。
3. **卖出比买入难**：买入只需 1 天满足条件；卖出需要多次确认（sell_threshold），防止震荡洗出。
4. **量价记忆**：买入时的市场状态决定卖出难度，实现"怎么买的就怎么卖"的对称性。

### 已知局限
1. **样本量不足**：仅 4 轮完成交易，统计显著性不够（需 15+ 轮）
2. **参数拟合风险**：sell_threshold 公式是针对历史案例校准的
3. **制度依赖**：策略在 924 行情后的牛市环境中设计，未经历完整熊市检验
4. **T+1 份额延迟**：ETF 份额数据滞后一天，极端行情下可能错过最佳时机
5. **单一标的**：目前仅监控 510300，未覆盖行业/主题 ETF 的轮动

## 九、与 ifund 选基系统的协同

```
Resonance（择时）→ 决定"什么时候买卖"
ifund（选基）  → 决定"买什么基金"
```

- Resonance 发出买入信号 → ifund 在该日期用预设条件筛选基金（C类、夏普3y>0.7、股票仓位>80%）→ 聚类分散化 → 等权配置 30-40 只
- Resonance 发出卖出信号 → 全部清仓
- 组合效果：+58.9% vs 基准 +33.3%，超额 +25.6%，MDD -4.17%
