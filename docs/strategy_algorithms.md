# 共振买卖点策略算法文档

> 同频（Resonance）ETF 国家队资金监控系统 · 四只 ETF 的买卖点算法完整说明

---

## 一、共同框架：量价记忆

四只 ETF 共享同一个核心机制：

```
买入当天量比越大 → 卖出需要的 DISTRIBUTE 确认次数越多
```

**逻辑**：天量接盘意味着筹码交换充分，需要更多出货确认才能判定趋势逆转。

**量价记忆公式**：

```
ratio = 当日成交量 / 前20日均量
sell_threshold = max(2, ceil(2 + ratio × 0.55))
```

| 买入日量比 | sell_threshold | 含义 |
|-----------|---------------|------|
| 极冷市 | 1 | 1次出货确认即可卖 |
| 1.0x | 3 | 需3次确认 |
| 3.0x | 4 | 需4次确认 |
| 5.0x | 5 | 需5次确认 |

---

## 二、信号定义

所有 ETF 共用同一套信号计算：

- **ACCUMULATE**（吸筹）：`price_position ≤ 40` + `volume_ratio ≥ 1.5`
- **DISTRIBUTE**（出货）：`price_position ≥ 70` + `volume_ratio ≥ 1.5`
- **NEUTRAL**（中性）：其余情况

其中 `price_position = (close - low_60d) / (high_60d - low_60d) × 100`

## 三、510300 华泰柏瑞沪深300ETF

**策略类型**：左侧 V1 量价记忆（趋势型）

### 买入条件（三选一）

| 路径 | 条件 | 逻辑 |
|------|------|------|
| 路径1 | `ACCUMULATE` + `pp ≤ 40` + `sp ≥ 65` | 价格低位 + 份额净申购 + 吸筹 |
| 路径2 | `ACCUMULATE` + `pp ≤ 40` + `成交额分位 ≤ 10` | 价格低位 + 吸筹 + 市场极冷 |
| 路径3 | `ACCUMULATE` + `pp ≤ 10` + `cp > 60` | 价格极低位 + 吸筹 + 综合概率高 |

### 卖出条件

**出货确认计数**：`DISTRIBUTE` + `pp ≥ 80` + `融资分位 ≥ 90` → `dist_count += 1`

**触发卖出**：`持仓 ≥ 10天` + `当日DISTRIBUTE` + `dist_count ≥ sell_threshold`

### 关键参数

| 参数 | 值 | 说明 |
|------|-----|------|
| SELL_PP | 80 | 卖出价格位置下限 |
| SELL_MP | 90 | 卖出融资分位下限 |
| MIN_HOLD | 10 | 最短持仓天数 |
| TRADE_START | 2024-10-08 | 策略起始日（924后） |

### 差异化特征

- 最成熟的策略，经过长期实盘验证
- 融资分位是卖出确认的关键维度
- 不依赖份额数据做卖出判断

## 四、589680 科创综指ETF

**策略类型**：左侧 V1 量价记忆（高波动趋势型）

### 买入条件（五路径）

| 路径 | 条件 | 逻辑 |
|------|------|------|
| 路径1 | `ACCUMULATE` + `pp ≤ 40` + `sp ≥ 60` | 吸筹 + 低位 + 份额 |
| 路径2 | `ACCUMULATE` + `pp ≤ 15` | 极端低位（不管份额） |
| 路径3 | `ACCUMULATE` + `pp ≤ 30` + `vr ≥ 1.5` | 恐慌接筹 |
| 路径4 | `chg ≤ -4.5%` + `vr ≥ 0.8` + `pp ≤ 40` | 极端暴跌（类吸筹） |
| 路径5 | `chg ≤ -3%` + `vr ≥ 1.5` + `pp ≤ 35` | 恐慌暴跌 |

### 类吸筹判定 `_is_quasi_accum()`

因为科创综指 ACCUMULATE 信号极稀缺（仅 1.2%），补充 NEUTRAL 中的实质吸筹日：

- 极低位（`pp ≤ 20`）：排除 DISTRIBUTE 日即可
- 低位（`pp ≤ 40`）：需要放量（`vr ≥ 1.3`）+ 资金流入（`sp ≥ 60` 或 `sd ≥ 3%`）
- 恐慌暴跌：`chg ≤ -4.5%` + `vr ≥ 0.8` + `pp ≤ 40`

### 卖出条件

**出货确认计数**：`DISTRIBUTE` + `pp ≥ 80` + `vr ≥ 1.4` → `dist_count += 1`

**触发卖出**：`持仓 ≥ 5天` + `当日DISTRIBUTE` + `dist_count ≥ sell_threshold`

### 关键参数

| 参数 | 值 | 说明 |
|------|-----|------|
| SELL_PP | 80 | 与510300一致 |
| SELL_VR | 1.4 | 出货量比确认 |
| MIN_HOLD | 5 | 科创波动大，可缩短 |
| COOLDOWN | 3 | 买入冷却期 |
| MIN_ETF_AGE | 60 | 极低位路径需ETF满60天 |

### 差异化特征

- ACCUMULATE 极稀缺（16个月仅4次） → 类吸筹判定补充
- "拉高出货"模式清晰：DISTRIBUTE 集群后 1-4 周急跌
- 份额数据波动大（单日 ±16%），用原始 `sd%` 辅助判断
- 卖出门槛基数从 2 降到 1（DISTRIBUTE 密度更低）

## 五、515080 中证红利ETF

**策略类型**：右侧 V1 量价记忆（均值回归型）

### 核心认知

中证红利是均值回归型资产，不适合左侧抄底：
- 被成长板块虹吸时跌幅可以很深很久
- `pp = 20` 买入后可能继续跌到 `pp = 2`
- 需要用右侧确认：超卖后等待价格企稳再入场

### 买入条件（三路径）

| 路径 | 条件 | 逻辑 |
|------|------|------|
| 危机左侧 | `ACCUMULATE` + `chg ≤ -3.5%` + `pp ≤ 25` | 系统性危机抢筹 |
| 右侧确认 | 超卖集群后连续2天涨+放量 | 均值回归确认 |
| 极冷吸筹 | `ACCUMULATE` + `pp ≤ 40` + `成交额分位 ≤ 10` | 市场遗忘=价值低估 |

### 超卖检测与右侧确认

**Phase 1 超卖检测**（不买入）：
```
最近10天 ≥ 2个 ACCUMULATE + pp ≤ 25 → 进入"等待确认"
```

**Phase 2 右侧确认**（触发买入）：
```
连续2天 chg > 0 + vr第二天 > 1.0 + vr第一天 > 0.8 + pp ≤ 40
OR 单日 chg > 2% + vr > 1.2 + pp ≤ 40
```

### 卖出条件

**出货确认计数**：`DISTRIBUTE` + `pp ≥ 75` + `vr ≥ 1.3` → `dist_count += 1`

**触发卖出**：`持仓 ≥ 8天` + `当日DISTRIBUTE` + `dist_count ≥ sell_threshold`

### 关键参数

| 参数 | 值 | 说明 |
|------|-----|------|
| SELL_PP | 75 | 低于510300（红利波动小） |
| SELL_VR | 1.3 | 出货量比确认 |
| MIN_HOLD | 8 | 最短持仓 |
| TRADE_START | 2024-01-01 | 数据起始日 |

### 差异化特征

- **均值回归型**——涨多跌、跌多涨，不适合左侧抄底
- 被板块虹吸时跌幅深久——需要右侧确认
- 低波动（区间 1.17-1.65，仅 42%）
- 卖出不需要融资门槛（红利与两融相关性弱）
- 极冷市不降低卖出门槛（"冷落"=价值低估，应持有更久）

### 回测表现

| 轮次 | 买入 | 卖出 | 收益 |
|------|------|------|------|
| 1 | 2024-01-22 @1.165 | 2024-09-26 @1.378 | +18.3% |
| 2 | 2025-04-07 @1.342 | 2025-08-22 @1.528 | +13.9% |
| 3 | 2025-11-24 @1.519 | 2026-03-09 @1.618 | +6.5% |

## 六、512100 中证1000ETF

**策略类型**：右侧 V1 量价记忆（高波动情绪型）

### 核心认知

- 暴跌集群特征明显：连续 5-9 个 ACCUMULATE 密集出现
- 左侧抄底会在集群中段入场，继续承压 5-10%
- 需要等待集群结束 + 反弹确认后右侧入场
- 买卖集中，不存在温和出货

### 买入条件（六路径）

| 路径 | 条件 | 逻辑 |
|------|------|------|
| 暴跌抄底 | `ACCUMULATE` + `chg ≤ -5%` | 单日极端暴跌 |
| 极端低位 | `ACCUMULATE` + `pp ≤ 10` | 极低位无条件 |
| 低位吸筹 | `ACCUMULATE` + `pp ≤ 25` + `sp ≥ 50` | 低位+份额 |
| 极冷吸筹 | `ACCUMULATE` + `pp ≤ 25` + `成交额 ≤ 10` | 极冷市 |
| 恐慌接筹 | `chg ≤ -3%` + `vr ≥ 1.5` + `pp ≤ 35` | 恐慌放量 |
| 反弹确认 | 跌超 7% + `ACCUMULATE` + `chg > 0` + `pp ≤ 30` | 超跌反弹 |

### 暴跌集群检测与右侧确认

**Phase 1 集群检测**：
```
最近10天 ≥ 2个 ACCUMULATE → 进入"等待右侧确认"
```

**Phase 2 右侧确认**（集群结束后触发）：
```
连续2天 chg > 0 + vr > 1.0 + pp ≤ 35
OR 单日 chg > 2% + vr > 1.0 + pp ≤ 35
```

**集群结束判定**：
```
最近10天 < 2个 ACCUMULATE OR 连续2天无ACCUMULATE
```

### 卖出条件（双路径）

**路径1 — 巨量流出**：
```
单日 sd_yi ≤ -5亿 + 近3天无≥5亿流入 + 累计净流入回撤>50%
```

**路径2 — DISTRIBUTE 集群确认**：
```
DISTRIBUTE + pp ≥ 75 + vr ≥ 1.3 → dist_count += 1
dist_count ≥ sell_threshold + 当日DISTRIBUTE → 卖出
```

### 关键参数

| 参数 | 值 | 说明 |
|------|-----|------|
| BUY_PP_MAX | 25 | 买入位置上限（波动大） |
| SELL_PP | 75 | 卖出位置下限 |
| SELL_VR | 1.3 | 出货量比确认 |
| MIN_HOLD | 5 | 最短持仓 |
| COOLDOWN | 3 | 交易冷却期 |

### 差异化特征

- **高波动情绪型**——暴跌集群中需等右侧确认
- 买卖集中，DISTRIBUTE 信号更可靠
- 单日极端暴跌（-5%）可直接左侧买入
- 巨量份额流出可触发快速卖出
- 卖出门槛与 510300 统一为 `ceil(2 + vr×0.55)`
- 近期大额流入（3天内）会阻止巨量流出卖出

## 八、设计原则

1. **量价关系是核心**——价格、成交量、份额变化是唯一客观可观测的数据
2. **每个 ETF 量价关系不同**——不能用同一套参数，需独立设计
3. **跟随而非预测**——识别大资金已发生的动向，而非预测未来走势
4. **卖出比买入难**——买入 1 天即可，卖出需多次确认
5. **924 前后两套市场**——策略起始日均为 2024-10-08（科创综指和部分标的除外）
